[04]$ publish --subscribe把自选配置变成订阅链接

上面生成的配置是下载到手机里的文件，Shadowrocket 没法直接从网页里抓它。想长期用一个固定链接订阅，需要先把文件传到仓库的 configs/ 文件夹。

  1. 点「下载 .conf」把文件存到手机
  2. 打开 GitHub 仓库 → configs 文件夹 → Add file → Upload files，上传刚才的文件
  3. 回到这里点「一键导入」，或复制下面的远程配置地址，到 Shadowrocket「配置」→ + → 粘贴 → Download
